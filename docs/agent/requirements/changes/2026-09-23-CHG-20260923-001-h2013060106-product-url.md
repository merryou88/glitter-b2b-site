# H2013060106 Product URL

## 变更原因
H2013060106 的公开标题和产品类型已经统一为 `Dense Dot Foil Suede-Look Fabric`，但原 URL 仍使用 `non-shedding-glitter-suede-look-laser-foil-fabric`。旧地址包含未被当前产品定位支持的 `non-shedding` 和 `glitter` 表述，并与 H1、Meta Title 和 Product Type 不一致。

## 变更前
公开产品地址为：

`/products/non-shedding-glitter-suede-look-laser-foil-fabric/`

## 变更后
公开产品地址改为：

`/products/dense-dot-foil-suede-look-fabric/`

旧地址的带斜杠和不带斜杠版本均永久 301 重定向到新地址。首页、产品列表、产品详情数据、询盘产品白名单和当前运营文档中的站内引用同步使用新地址。

## 验收条件
- `/products/dense-dot-foil-suede-look-fabric/` 可生成并显示 H2013060106 的现有详情内容。
- 旧地址的带斜杠和不带斜杠版本均通过 Cloudflare Pages `_redirects` 301 到新地址。
- 新地址的不带斜杠版本 301 到规范的带斜杠版本。
- sitemap 只输出新产品地址。
- 站点运行数据和页面代码不再引用旧 slug。
- 产品标题、Meta Title、描述、规格、图片和应用内容不因本次 URL 变更而改变。
- `npm run validate:products`、`npm run build` 和 `git diff --check` 通过；如因工作区中既有缺失图片失败，应记录为非本次变更引入。

## 影响范围
仅改变 H2013060106 的公开 URL 和直接引用。保留旧地址兼容性，不改变产品内容、询盘接口或公共页面布局。

## 兼容性
旧链接通过永久 301 重定向继续有效。部署后应在 Google Search Console 检查新地址并请求编入索引。

- 通过：新页面 H1、Meta Title 和 canonical 使用新地址及既有产品标题。
- 通过：sitemap 只包含新产品地址，不包含旧地址。
- 通过：H2013060106 页面引用的 18 个图片素材均存在。
