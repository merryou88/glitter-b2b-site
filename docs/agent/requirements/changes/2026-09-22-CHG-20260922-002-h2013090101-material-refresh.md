# H2013090101 Material Refresh

## 变更原因
用户更新了 H2013090101 的主图和详情图素材，并要求只更新该产品的图片内容及水印。

## 变更前
产品页仍引用旧的 `a1–a5.webp` 主图集合和 `detail/1–9、11.webp` 详情图集合，且新素材未按当前水印规则完整处理。

## 变更后
- 主图集合更新为 `main/1.webp`、`main/2.webp`、`main/a1.webp`、`main/a2.webp`、`main/a3.webp`。
- 详情图集合更新为 `detail/1.webp` 至 `detail/8.webp`。
- `main/1.webp` 作为首张主图保持无水印。
- 其余 4 张主图和 8 张详情图均添加 3 个分散、不重叠、低透明度、逆时针 45 度倾斜的 `nixiafabric.com` 水印。
- 仅修改 H2013090101 的素材引用和图片文件，不改动其他产品的素材。

## 验收条件
- 产品页不再引用不存在的 `main/a4.webp`、`main/a5.webp`、`detail/9.webp` 或 `detail/11.webp`。
- H2013090101 页面构建成功并引用当前主图和详情图。
- 首张主图无水印，其余主图及详情图完成水印处理。

## 实现位置
- `src/data/allProducts.js`
- `public/images/products/H2013090101/main/`
- `public/images/products/H2013090101/detail/`

## 验证结果
- 通过：Astro 静态页面构建，H2013090101 路由生成成功。
- 通过：H2013090101 页面定向检查，当前图片引用均存在。
- 通过：人工抽查首张主图和加水印图片。
- 未通过：项目级 `npm run build` 的最后一步 `npm run validate:products`，原因是其他既有产品 `iridescent-laser-hot-stamping-stretch-ice-silk` 和 `iridescent-gradient-laser-ice-silk` 的图片已缺失；未恢复这些非本次任务的用户删除素材。
