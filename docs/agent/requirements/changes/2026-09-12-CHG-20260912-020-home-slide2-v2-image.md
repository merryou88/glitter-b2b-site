# 更新首页 Slide 2 V2 素材

## 变更原因
首页第二张轮播图已替换为 `slide2_v2` 新素材。

## 变更前
`slide2` 使用 `slide2.png` 及其对应 WebP 变体。

## 变更后
`slide2` 改用 `slide2_v2.png`，并生成对应的桌面端 `slide2_v2.webp` 与移动端 `slide2_v2-mobile.webp`。

## 验收条件
- 首页第二张轮播显示 `slide2_v2` 新素材。
- 桌面端和移动端均加载对应 WebP 变体。
- 其他轮播内容、文案和交互不受影响。

## 影响范围
仅更新首页第二张轮播的图片素材引用及适配文件。

## 实现位置
`src/components/HeroCarousel.astro`、`public/images/home/slide2_v2.png`、`public/images/home/slide2_v2.webp`、`public/images/home/slide2_v2-mobile.webp`

## 验证结果
已执行 `npm run build`，并检查生成首页的 `slide2_v2` 素材引用。

## 来源
用户明确要求将首页 `slide2` 替换为 `slide2_v2`。
