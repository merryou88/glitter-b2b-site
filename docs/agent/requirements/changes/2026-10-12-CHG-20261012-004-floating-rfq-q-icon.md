# 浮动询盘入口改为黄色 Q

## 变更原因
用户指定大写 Q 和 CTA 同色黄色背景。
## 变更前
深蓝圆形背景和文档图标。
## 变更后
白色大写 Q，背景复用 `--color-accent`；保留位置和交互。
## 验收条件
移动端显示黄色圆形 Q，点击仍打开现有表单。
## 影响范围
更新 REQ-FORM-006 视觉规则，其他规则不变。
## 兼容性
不改变表单字段或提交逻辑。
## 实现位置
`src/components/RFQQuoteModal.astro`
## 验证结果
npm run build 通过，包含产品与 SEO 校验；代码核对确认使用与 primary CTA 相同的 --color-accent 变量。仅更换标志与样式，交互复用已验证逻辑。
## 来源
用户要求替换图标为 Q 并使用 CTA 黄色。
