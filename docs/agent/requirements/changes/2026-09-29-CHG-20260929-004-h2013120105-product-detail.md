# H2013120105 全息鱼鳞牛奶丝四面弹面料产品详情页

## 变更原因
用户确认 H2013120105 产品素材已存放在 `public/images/products/H2013120105/`，并要求生成该产品详情页。当前产品详情页生成规则要求：所有产品事实先读取 `products-data/面料独立站产品数据.xlsx` 的 `Independent Site Product Data` sheet，再使用图片素材补充展示。

## 变更前
- H2013120105 未进入 `performanceProducts` 公开产品集合。
- `public/images/products/H2013120105/` 中只有 PNG 素材，未生成站点引用的 WebP 展示图。
- 候选计划中 H2013120105 仍记录为空图片目录占位，供货、样品、交期和完整素材未确认。

## 变更后
- 新增公开产品 `holographic-mermaid-scale-milk-silk-stretch-fabric`，SKU 为 H2013120105。
- 页面数据以 `面料独立站产品数据.xlsx` 的 `Independent Site Product Data` sheet 中 H2013120105 行为准：H1 为 `Holographic Mermaid Scale Milk Silk 4-Way Stretch Fabric`，SEO 标题为 `Holographic Mermaid Scale Milk Silk 4-Way Stretch Fabric for Stage Costumes | Nixia Fabric`。
- 页面定位为 holographic mermaid-scale foil、high-stretch milk-silk base 和 4-way stretch fabric，推荐应用为 mermaid skirts、stage costumes、dancewear 和 performance outfits。
- 规格按表格确认：150 cm / 59 in、180 GSM、MOQ 100 m / 109 yd、11 colors、high stretch / 4-way stretch、86T、hot-stamping foil mermaid-scale pattern 和 92% Polyester 8% Spandex。纱支、库存、测试合规和贸易条款保持 `To be confirmed` 或项目确认表述。
- 主图整理为 `a1.webp`-`a5.webp`；详情图按内容顺序整理为 `x1.webp`-`x9.webp`；没有独立 application 素材时不生成虚构应用图。
- PNG 原图归档到 `products-data/original-images/images/products/H2013120105/`，线上目录只保留 WebP。
- `main/a1.webp` 无水印；其余主图和详情图 WebP 各添加 3 个低透明度、逆时针 45 度倾斜的 `nixiafabric.com` 域名水印。
- 详情页不输出独立 `Product Description` 模块。

## 验收条件
- `/products/holographic-mermaid-scale-milk-silk-stretch-fabric/` 能生成并进入公开产品集合。
- 产品目录、静态路由、询盘产品选择和相关推荐使用 `performanceProducts` 中的 15 个产品。
- 页面包含 Key Features、Recommended Applications、Why Choose、Ready Stock & Custom Development、Sample CTA 和 FAQ。
- 页面字段先读取 `Independent Site Product Data` 中 H2013120105 行；未提供来源的纱支、库存、测试合规和贸易条款保持待确认或项目确认表述。
- 页面源码不包含独立 `Product Description` 标题，且不引用 H2013120105 PNG 原图。

## 影响范围
产品数据、产品公开集合、H2013120105 图片资源、产品详情页和候选产品计划。
