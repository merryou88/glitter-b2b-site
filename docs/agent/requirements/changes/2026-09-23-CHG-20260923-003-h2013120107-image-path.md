# H2013120107 Image Path

## 变更原因
用户确认 `iridescent-laser-hot-stamping-stretch-ice-silk` 的公开图片和视频素材实际存放在 `public/images/products/H2013120107/`。产品、博客和应用场景页面仍引用以产品 slug 命名的旧目录，导致构建后的页面产生缺失素材校验错误。

## 变更前
产品主图、画廊、详情图、视频、博客图片和应用图片引用：

`/images/products/iridescent-laser-hot-stamping-stretch-ice-silk/`

## 变更后
相关素材统一引用：

`/images/products/H2013120107/`

产品公开 slug 和页面 URL `iridescent-laser-hot-stamping-stretch-ice-silk` 保持不变。

## 验收条件
- 产品主图和画廊读取 `H2013120107/main/`。
- 产品详情图读取 `H2013120107/detail/`。
- 产品视频读取 `H2013120107/video/1.mp4`，poster 读取同产品主图目录。
- 产品详情页 Application 图片由主图目录推导并读取 `H2013120107/application/`。
- 博客和应用场景页面中的相关图片同步使用 `H2013120107`。
- 构建产物不再引用 `/images/products/iridescent-laser-hot-stamping-stretch-ice-silk/`。
- `npm run validate:products`、`npm run build` 和 `git diff --check` 通过。

## 影响范围
仅修正 H2013120107 产品及其博客、应用页引用的素材目录，不改变产品 URL、标题、规格、文案或询盘流程。

## 兼容性
产品公开URL不变，无需重定向。

## 实现位置
- `src/data/allProducts.js`
- `src/data/products.json`
- `src/data/blogArticles.js`
- `src/pages/applications/index.astro`
- `src/pages/applications/[slug].astro`
- `docs/agent/requirements/current/content-data.md`
- `docs/agent/requirements/INDEX.md`
