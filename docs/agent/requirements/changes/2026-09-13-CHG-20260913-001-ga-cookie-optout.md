# GA Cookie Opt-Out

## 背景
站点原先在所有页面无条件加载 GA4。用户自己访问站点时会经过中转代理，出口 IP 可能变化，因此仅依赖 GA4 内部流量 IP 过滤无法稳定排除自己的访问数据。

## 变更前
- `src/layouts/Layout.astro` 直接在 `<head>` 中静态加载 `https://www.googletagmanager.com/gtag/js?id=G-VDYGZBSQ62`。
- 页面初始化时总是执行 `gtag("config", "G-VDYGZBSQ62")`。

## 变更后
- `src/layouts/Layout.astro` 先检查浏览器 Cookie。
- 当 `document.cookie` 中存在 `nixia_ga_optout=true` 时，直接跳过 GA4 脚本加载和配置事件。
- 默认访客没有该 Cookie 时，仍动态加载同一个 Google tag，并发送 `G-VDYGZBSQ62` 配置事件。

## 验收条件
- 默认访问者继续加载 GA4。
- 设置 `nixia_ga_optout=true` Cookie 的浏览器不会请求 GA4 脚本，也不会发送 GA4 配置事件。
- 不在单独页面重复添加 Google tag。

## 影响范围
- 代码路径：`src/layouts/Layout.astro`
- 需求路径：`docs/agent/requirements/current/site-shell.md`

## 验证
- 已执行：`npm run build`
- 结果：构建成功，产品数据校验通过；抽查 `dist/index.html`、`dist/products/index.html`、`dist/contact/index.html`，均包含 `nixia_ga_optout=true` 判断和单次 `G-VDYGZBSQ62` 配置。
