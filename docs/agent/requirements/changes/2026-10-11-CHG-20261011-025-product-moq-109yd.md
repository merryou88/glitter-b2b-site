# 指定产品 MOQ 统一为 109 yd

## 变更前

`iridescent-gradient-laser-ice-silk` 在产品数据、规格和 FAQ 中使用 `109 yd per colorway`，旧版 `src/data/products.json` 也保留了同样的写法。

## 变更后

目标产品的 MOQ 对外统一展示为 `109 yd`。FAQ 和产品摘要在需要表达颜色维度时保留 `per colorway`，但不再展示公制单位和双单位写法。

## 验收标准

- 目标产品的详情页 MOQ、规格和 FAQ 均显示 `109 yd`。
- 产品数据中不再出现 `109 yd per colorway`。
- 未带 `per colorway` 的其他产品 MOQ 不受影响。

## 影响与实现

- 影响模块：`product-catalog`、`content-data`
- 实现位置：`src/data/allProducts.js`、`src/data/products.json`

## 验证结果

待运行 `npm run validate:products`、`npm run build` 和定向文本扫描。
