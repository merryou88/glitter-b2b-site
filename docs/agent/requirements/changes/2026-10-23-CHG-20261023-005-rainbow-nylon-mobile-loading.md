# H2013120101 产品详情页移动端加载优化

## 变更原因
用户反馈 `/products/rainbow-iridescent-laser-foil-nylon-spandex-fabric/` 打开速度慢，要求优化。

## 变更前
五张画廊源图均为 800px WebP，合计 426,898 字节；缩略图直接引用完整源图，浏览器在初次加载时同时下载五张图。该页存在两个阻塞样式请求。

## 变更后
- 在现有定向优化白名单中加入 H2013120101，并仅导入该产品的五张画廊源图；复用此前 H2013120107 的处理逻辑与共享详情组件。
- 生成 480/720/800px、质量 76 的响应式主图，不放大源图；缩略图使用 160px、质量 70 的 WebP。首图预加载与实际 source 的 `srcset/sizes` 一致，避免原图或重复首图下载。
- 生产构建将该详情页本地 CSS 内联，减少两次阻塞样式请求。

## 验收条件
五张画廊图片可切换并返回首图，首图与缩略图采用优化资源；无重复首图请求、无本地资源 404；375/390/768/1024/1440px 无横向溢出，询盘弹窗正常；现有首页、目录与 H2013120107 优化保留，其他详情页维持原图路径及外部 CSS。

## 影响范围
`src/pages/products/[slug].astro`、`scripts/inline-home-styles.mjs`；复用现有 `ProductDetail.astro`，不修改共享组件。

## 兼容性
产品数据、文案、规格、图片顺序、详情图片、SEO、RFQ 和统计不变。该产品没有视频，未新增视频入口；源图文件不覆盖。REQ-PRODUCT-055 继续适用于 H2013120107，本记录为新增产品优化范围。

## 验证结果
- `npm run build` 通过；18 个产品、59 个 HTML 页面、56 个 sitemap URL 及内部链接校验通过。
- 浏览器检查 375/390/768/1024/1440px：五张图片切换并返回首图、quote/sample RFQ 打开及关闭均正常，无横向溢出和页面 JavaScript 错误。
- 本机同源重放优化前构建与优化产物，390×844、DPR 2、150ms 延迟、200,000 B/s 下行、CPU 4 倍节流、禁用缓存，各三次：LCP 中位数 2368ms → 1156ms（约减少 51%），FCP 中位数 664ms → 308ms；初次图片下载合计 426,898 → 90,872 字节（约减少 79%）。首图从 97,288 → 65,328 字节，无原图或重复首图请求；两版画廊顶部均约 166.8px，资源无 404。
- 静态检查确认首图 480/720/800px 候选与实际输出尺寸相符，大小为 35,196/65,328/91,924 字节；五张 160px 缩略图合计 25,544 字节。H1、title 和 canonical 与修改前一致。
- H2013120107 的响应式首图路径及样式内联保留；另一个未优化产品 `iridescent-gradient-laser-ice-silk` 的原图切换回归通过。
- `git diff --check` 通过。尚未提交或部署；本机模拟结果不等于线上 Lighthouse 得分或目标地区实际网络速度，发布后需复测。

## 来源
用户当前关于此产品页打开速度的反馈。
