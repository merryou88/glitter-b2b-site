# 修复移动端 RFQ 弹窗关闭按钮

## 变更原因
移动端 RFQ 弹窗中的关闭按钮与深色侧栏对比度不足，且弹窗滚动结构可能影响按钮的稳定点击。

## 变更前
移动端复用桌面端关闭按钮的半透明背景和较小触控区域，按钮位于弹窗内容层中。

## 变更后
移动端关闭按钮固定在视口右上方，提升到更高层级，使用白色背景、阴影和 44px 触控区域，确保始终可见可点击。

## 验收条件
- 移动端 RFQ 弹窗打开后可看到关闭按钮。
- 点击关闭按钮后弹窗关闭，页面滚动恢复。
- 桌面端关闭按钮样式和行为保持不变。

## 影响范围
仅调整 RFQ 弹窗移动端关闭按钮的定位、层级、对比度和尺寸。

`src/components/RFQQuoteModal.astro`
