# 首页 Hero 特点移动端两列展示

## 变更原因
首页 Hero 下方的四个特点在移动端使用单列布局，导致区块过长且文字尺寸没有针对手机屏幕调整。

## 变更前
移动端 `.hero-trust__grid` 使用单列布局，四个特点依次纵向展示。

## 变更后
移动端改为两列等宽网格，每行展示两个特点；数值和说明文字使用响应式字号，说明文字限制在网格单元内换行。

## 验收条件
- 375px、390px 和 768px 宽度下，四个特点按两行两列展示。
- 特点标题和说明文字不溢出、不重叠。
- 桌面端仍保持四列布局。

## 影响范围
仅调整首页 Hero 下方特点区块的移动端布局和字号。

## 实现位置
`src/pages/index.astro`

## 验证结果
待执行构建验证。

## 来源
用户明确要求首页 Hero 下方四个特点在移动端按两列同行展示并自适应字号。
