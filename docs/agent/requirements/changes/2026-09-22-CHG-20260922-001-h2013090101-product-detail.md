# H2013090101 Product Detail

## 变更原因
用户提供了 H2013090101 的产品图片，并要求按现有产品生成规则制作公开产品详情页。

## 变更前
H2013090101 只存在于产品资料表和候选记录中，没有进入当前公开产品数据、产品列表或静态详情路由。原始主图和详情 JPG/PNG 尚未生成线上 WebP。

## 变更后
新增公开产品 `holographic-snakeskin-stretch-fabric`，标题为 `Laser Foil Snakeskin Stretch Fabric`，SKU 为 `H2013090101`。页面使用资料表中已确认的 147 cm / 58 in、160 GSM、100 m / 109 yd MOQ、70 colors、slight stretch 和 92% Polyester 8% Spandex，并展示 Swimwear、Leggings、Dancewear、Stage Costumes 和 Mermaid Costumes 应用。

主图使用 `a1.webp` 至 `a5.webp`，详情图按实际素材使用 `1.webp` 至 `9.webp` 和 `11.webp`。`a1.webp` 无水印，其余主图和详情图 WebP 各添加 3 个分散、不重叠、低透明度、逆时针 45 度倾斜的 `nixiafabric.com` 水印。没有独立 application 图片，因此不生成虚构的应用场景图。原始 PNG/JPG 已归档到 `products-data/original-images/images/products/H2013090101/`。

## 验收条件
- `/products/holographic-snakeskin-stretch-fabric/` 可生成并打开。
- 产品列表包含该产品，显示 70 colors、147 cm / 58 in、160 GSM、MOQ 100 m / 109 yd 和 Made to Order。
- 详情页包含 Product Name / SKU、B2B specifications、应用、FAQ、Sample CTA 和 RFQ 产品上下文。
- 线上公开素材只引用 H2013090101 WebP，不引用原始 PNG/JPG。
- 不擅自生成缺失的 `10.webp`，详情图实际引用 `1–9、11`。
- 新产品定向检查通过：静态页包含 H1、Product Name / SKU、H2013090101、70 colors、Made to Order，并只引用 H2013090101 的 WebP 素材；未引用产品 JPG/PNG，也未引用不存在的 `detail/10.webp`。
- `npm run build` 和 `git diff --check` 通过。
- `npm run validate:products` 未通过，原因是工作区中其他既有产品的图片已缺失（`iridescent-laser-hot-stamping-stretch-ice-silk`、`iridescent-gradient-laser-ice-silk`）；该失败与 H2013090101 新增页面无关，未恢复用户已有删除。

## 影响范围
新增一个公开产品及其列表/详情页入口；不改变已有产品 URL、询盘接口、价格逻辑或公共布局。
