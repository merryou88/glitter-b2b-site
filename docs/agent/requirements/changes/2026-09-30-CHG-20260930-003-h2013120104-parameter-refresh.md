# H2013120104 产品参数表更新

## 变更原因
用户要求 H2013120104 产品详情页参数根据产品参数表更新。`Independent Site Product Data` sheet 中 H2013120104 行已补充宽幅、克重、MOQ、弹性、纱支、后整理、花型结构和底材信息。

## 变更前
- H2013120104 页面中 width、weight、MOQ、base material、yarn count、finishing 和 pattern / construction 多处显示 `To be confirmed`。
- FAQ 和说明文案仍提示宽幅、克重、MOQ、底材、结构和纱支需要确认。

## 变更后
- Width 更新为 `145 cm / 57 in`。
- Weight 更新为 `150 GSM`。
- MOQ 更新为 `200 m / 219 yd`。
- Stretch 更新为 `4-Way Stretch`。
- Composition / Base Fabric 更新为 `98% Polyester / 2% Spandex`。
- Yarn Count 更新为 `30s`。
- Finishing 和 Pattern / Construction 更新为 `Hot-stamping foil`。
- 首屏亮点、Key Features、Value Story、Sample CTA、FAQ 和采购表同步使用已确认参数。
- 颜色数量、密度、库存、测试合规和贸易条款仍保持待确认或项目确认表述。

## 验收条件
- `/products/rainbow-fingerprint-dot-foil-ice-silk-fabric/` 显示已确认参数。
- 页面不再把已确认的宽幅、克重、MOQ、底材、四面弹、纱支和工艺写成待确认。
- 未确认字段仍不编造。
- 产品校验和构建通过。

## 影响范围
H2013120104 产品详情页、产品目录卡片参数、询盘产品上下文和候选产品计划说明。
