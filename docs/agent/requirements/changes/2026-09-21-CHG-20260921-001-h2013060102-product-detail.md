# H2013060102 彩虹条纹四面弹烫金面料产品详情页

## 变更原因
用户确认 H2013060102 素材并要求按统一产品详情页规则生成公开详情页。

## 变更前
- H2013060102 仅在下一批产品候选计划中记录，没有公开产品数据或静态详情页。
- `public/images/products/H2013060102/` 只有上传 PNG 素材，未生成站点引用的 WebP 展示图。
- H2013060102 未进入 `performanceProducts` 公开产品集合。

## 变更后
- 新增公开产品 `rainbow-stripe-foil-4-way-stretch-fabric`，SKU 为 H2013060102。
- 使用来源资料已确认的英文标题、SEO 描述、应用和规格：150 cm / 59 in、180 GSM、MOQ 100 m / 109 yd、2 colors、4-way stretch、80T、300D*10S、hot-stamping foil、full-print effect 和 95% Polyester 5% Spandex。
- 主图整理为 `a1.webp`–`a5.webp`；详情图按内容顺序整理为 `x1.webp`–`x7.webp`；原 `x12.png` 应用拼图独立为 `application/1.webp`。
- PNG 原图归档到 `products-data/original-images/images/products/H2013060102/`，线上目录只保留 WebP。
- `main/a1.webp` 无水印；其余主图和详情图 WebP 各添加 3 个低透明度、逆时针 45 度倾斜的 `nixiafabric.com` 域名水印；应用图不加水印。
- 详情页不输出独立 `Product Description` 模块。

## 验收条件
- `/products/rainbow-stripe-foil-4-way-stretch-fabric/` 能生成并进入公开产品集合。
- 产品目录、静态路由、询盘产品选择和相关推荐使用 `performanceProducts` 中的 10 个产品。
- 页面包含 Key Features、Recommended Applications、Why Choose、Ready Stock & Custom Development、Sample CTA 和 FAQ。
- 页面仅展示已确认规格；库存、样品准备时间、批量交期、包装、贸易条款和测试合规保持项目确认表述。
- 页面源码不包含 `Product Description` 标题，且不引用 H2013060102 PNG 原图。

## 影响范围
产品数据、产品公开集合、H2013060102 图片资源、产品详情页和候选产品计划。

## 兼容性
