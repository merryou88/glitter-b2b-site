# 首页首屏询盘按钮直接打开 RFQ 弹窗

## 变更原因
用户要求截图中首页首屏 Request Sample & Quote 按钮点击后直接弹出 RFQ 表单。
## 变更前
按钮链接至 #rfq-buyer-resource；首页 floatingOnly 仅绑定浮动表单图标，首屏按钮不会打开弹窗。
## 变更后
首屏按钮增加 data-rfq-home-open 标记，首页弹窗将其与浮动入口一起绑定；点击阻止锚点跳转并直接打开现有 RFQ 表单，默认 General fabric inquiry 和 sample-and-quote，保留原 URL sku 上下文规则。
## 验收条件
桌面与移动端点击首屏按钮均直接打开 RFQ 弹窗；关闭按钮、遮罩、Esc、滚动锁定和焦点恢复复用现有行为；其他首页 CTA 和内联表单维持原行为。
## 影响范围
首页首张轮播主按钮与共享 RFQ 弹窗的首页入口筛选规则。
## 兼容性
保留原锚点作为 JavaScript 不可用时的回退；不改变表单字段、提交逻辑、Worker 或统计。
## 实现位置
src/components/HeroCarousel.astro、src/components/RFQQuoteModal.astro。
## 验证结果
`npm run build` 通过：59 个页面构建、18 个产品校验、56 个 sitemap URL 及全站 SEO/内链检查通过。生成首页 HTML 检查确认仅首屏目标按钮带 data-rfq-home-open、共享弹窗唯一、首页专用入口绑定生效且保留内联表单锚点。`git diff --check` 通过。未进行浏览器实际点击或真实询盘提交。
## 来源
用户当前明确要求及按钮截图。
