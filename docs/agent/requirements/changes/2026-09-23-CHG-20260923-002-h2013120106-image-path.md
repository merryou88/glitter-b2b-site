# H2013120106 Image Path

## 变更原因
用户确认 `iridescent-gradient-laser-ice-silk` 的公开图片和视频素材实际存放在 `public/images/products/H2013120106/`。产品和两篇博客仍引用以产品 slug 命名的旧目录，导致构建后的页面出现缺失素材校验错误。

## 变更前
产品主图、画廊、详情图、视频及两篇博客图片引用：

`/images/products/iridescent-gradient-laser-ice-silk/`

## 变更后
相关素材统一引用：

`/images/products/H2013120106/`

产品公开 slug 和页面 URL `iridescent-gradient-laser-ice-silk` 保持不变。

## 验收条件
- 产品主图和画廊读取 `H2013120106/main/`。
- 产品详情图读取 `H2013120106/detail/`。
- 产品视频读取 `H2013120106/video/1.mp4`，poster 读取同产品主图目录。
- Application 图片由产品主图目录推导并读取 `H2013120106/application/`。
- 使用该素材的博客图片同步改为 `H2013120106` 路径。
- 构建产物不再引用 `/images/products/iridescent-gradient-laser-ice-silk/`。
- `iridescent-gradient-laser-ice-silk` 不再产生缺失素材校验错误。

## 影响范围
仅修正 H2013120106 产品及其博客引用的素材目录，不改变产品 URL、标题、规格、文案或询盘流程。

## 兼容性
产品公开URL不变，无需重定向。

## 实现位置
- `src/data/allProducts.js`
- `src/data/products.json`
- `src/data/blogArticles.js`
- `docs/agent/requirements/current/content-data.md`
- `docs/agent/requirements/INDEX.md`

- 通过：Astro 静态构建生成产品页和相关博客页。
- 通过：构建产物不再引用 `/images/products/iridescent-gradient-laser-ice-silk/`。
- 通过：构建产物引用的 10 个 `H2013120106` 主图、详情图、Application 图片和视频素材全部存在。
- 通过：产品 URL、canonical 和 H1 保持不变。
- 通过：`iridescent-gradient-laser-ice-silk` 已不再产生产品素材校验错误，完整校验问题由 39 项降至 21 项。
