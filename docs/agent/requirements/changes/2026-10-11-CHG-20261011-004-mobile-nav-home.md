# 显示移动端 Home 菜单

## 变更原因
移动端菜单展开后，Home 菜单项被响应式样式隐藏，用户无法从菜单中直接返回首页。

## 变更前
移动导航 DOM 中存在 Home，但在 `max-width: 1100px` 规则中隐藏了第一项。

## 变更后
移除隐藏移动导航第一项的 CSS 规则，移动端菜单展开后正常显示 Home。

## 验收条件
- 移动端展开菜单时显示 Home。
- Home 链接指向 `/`。
- Products、Applications、Factory、About Us、Blog、Contact 和询盘按钮保持不变。
- 桌面端导航保持不变。

## 影响范围
仅调整站点 Header 的移动/窄屏菜单显示。

## 实现位置
`src/components/Header.astro`
