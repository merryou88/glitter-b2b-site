# H2013090102 Title, SKU, Image Path And Watermark Sync

## 变更原因
用户已将 `Iridescent Laser Foil 4-Way Stretch Fabric for Stage & Dancewear` 的图片目录从产品名目录统一迁移为产品编号 `H2013090102`，并要求同步产品详情里的 `Product Name / SKU` 字段、产品标题和展示图水印。

## 变更前
该产品标题显示为 `Iridescent Laser Foil 4-Way Stretch Fabric for Stage & Dancewear`，SKU 为 `P0001`，产品数据和部分站内图片引用仍指向 `/images/products/plain-iridescent-laser-spandex-4-way-stretch/`。新编号目录下的图片未按当前域名水印规则处理。

## 变更后
该产品展示标题统一为 `Iridescent Laser Foil 4-Way Stretch Fabric`，SKU 统一为 `H2013090102`，产品主数据和站内实际图片引用改为 `/images/products/H2013090102/`。`main/1.webp` 保持无水印；`main/2.webp` 到 `main/4.webp` 与 `detail/1.webp` 到 `detail/4.webp` 添加 3 个低透明度、逆时针 45 度倾斜域名水印 `nixiafabric.com`；Application 图片保持无水印。

补充修正：3 个域名水印必须分散放置，不能互相重叠或交叉遮挡；H2013090102 已从未加水印原图重新生成主图 2–4 和详情图 1–4，避免在错误水印图上继续叠加。

## 验收条件
- 产品详情页 H1 显示 `Iridescent Laser Foil 4-Way Stretch Fabric`。
- 产品详情页 `Product Name / SKU` 显示 `Iridescent Laser Foil 4-Way Stretch Fabric / H2013090102`。
- 产品主图、详情图、应用图均从 `/images/products/H2013090102/` 读取，不再从旧产品名图片目录读取。
- `main/1.webp` 无水印，其他主图和 Product Details WebP 图按域名水印规则处理，且 3 个水印不互相重叠。
- `npm run validate:products` 与 `npm run build` 通过。

## 影响范围
影响该产品的产品数据、站内图片引用、展示图片和需求文档；不改变产品 slug、产品详情页 URL、RFQ 表单字段或价格逻辑。

## 兼容性
