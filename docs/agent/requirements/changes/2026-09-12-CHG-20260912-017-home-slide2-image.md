# 更新首页 Slide 2 素材

## 变更原因
首页第二张轮播图已替换为新的产品展示素材。

## 变更前
`slide2` 使用旧的 `public/images/home/slide2.webp` 作为组件源路径。

## 变更后
`slide2` 改用新的 `public/images/home/slide2.png`；桌面端和移动端分别保留对应的 `slide2.webp` 与 `slide2-mobile.webp`，由轮播组件自动加载。

## 验收条件
- 首页第二张轮播显示新素材。
- 桌面端加载 `slide2.webp`，移动端加载 `slide2-mobile.webp`。
- 其他轮播内容、文案和交互不受影响。

## 影响范围
仅更新首页第二张轮播的图片素材引用及其适配文件。

## 实现位置
`src/components/HeroCarousel.astro`、`public/images/home/slide2.png`、`public/images/home/slide2.webp`、`public/images/home/slide2-mobile.webp`

## 验证结果
已执行 `npm run build`，并检查生成首页的轮播素材引用。

## 来源
用户明确要求更新首页 `slide2` 图片。
