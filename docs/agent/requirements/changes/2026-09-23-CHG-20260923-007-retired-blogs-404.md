# Retired Blog URLs Return 404

## 变更原因
用户确认4篇已经退出当前内容方向、且没有明确同主题替代文章的旧博客不应继续301到博客首页，应由站点返回404。

## 变更前
以下旧文章地址301到 `/blog/`：

- `/blog/cnas-certification-coarse-glitter-pu-hot-stamping-fabric/`
- `/blog/what-is-glitter-fabric/`
- `/blog/glitter-vs-foil-comparison/`
- `/blog/how-to-choose-glitter-surface-solid-leather-fabric/`

## 变更后
删除上述4条301规则。文章历史数据继续保留在 `allBlogArticles`，但被 `excludedBlogSlugs` 排除，不进入公开 `blogArticles` 集合，因此不生成静态文章页；旧地址由现有站点404页面处理。

## 验收条件
- `_redirects` 不再包含上述4篇文章到 `/blog/` 的规则。
- 构建产物不生成上述4篇文章详情页。
- sitemap不包含上述4篇文章URL。
- 构建产物不存在指向上述4篇文章的公开链接。
- 当前公开博客仍正常生成。
- `npm run build` 和 `git diff --check` 通过。

## 影响范围
只改变4篇已退出博客旧URL的响应方式；不删除历史文章数据，不改变当前公开博客内容或其他重定向。

## 兼容性
旧外部链接将进入品牌404页面，不再被送到不相关的博客首页。Google后续抓取时会将这些URL归类为未找到。

## 实现位置
- `public/_redirects`
- `docs/agent/requirements/current/blog.md`
- `docs/agent/requirements/INDEX.md`

## 验证结果
- 通过：`npm run build`，共生成 41 个页面。
- 通过：`npm run validate:products`，11 个公开产品全部通过校验。
- 通过：4篇旧博客地址均已从 `_redirects` 删除。
- 通过：构建产物未生成4篇旧博客详情页。
- 通过：sitemap不包含4篇旧博客URL。
- 通过：公开HTML中不存在指向4篇旧博客的链接。
- 通过：品牌 `404.html` 正常生成。
- 通过：`git diff --check`。

## 来源
用户明确要求4篇旧博客地址转到404。
