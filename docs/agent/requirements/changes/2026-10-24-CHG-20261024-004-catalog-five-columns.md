# 宽屏五列紧凑产品卡

## 变更原因
用户希望每行5个产品，标题字体缩小避免换行。
## 变更前
桌面3列，标题16px最多两行。
## 变更后
≥1280px五列，间距16px；中桌面三列、平板两列、手机一列。标题宽屏13px，其他14px，单行省略且title保留完整名称。五列卡片按钮纵向排列保证点击宽度；同步图片sizes与预加载实际卡宽。
## 验收条件
1280/1440/1920px为五列，1024三列、800两列、390一列；无横向溢出，标题单行，筛选与RFQ正常。
## 影响范围
仅目录卡片排版及相关需求文档。
## 兼容性
产品源名称、详情页、排序和RFQ流程不变；无部署。
## 实现位置
src/pages/products.astro
## 验证结果
`npm run build`通过（18产品、59页面、56 sitemap URL及内链）。本地Chrome检查390/800/1024/1280/1440/1920px，实际列数1/2/3/5/5/5；各尺寸无横向溢出，搜索、效果筛选、清除、空结果、索样与报价弹窗正常，无页面脚本错误。已视觉检查1440px五列截图。`git diff --check`通过。未发布或真实提交询盘。
## 来源
用户当前五列与标题字号调整要求。
