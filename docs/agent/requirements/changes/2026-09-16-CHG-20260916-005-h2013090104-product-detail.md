# H2013090104 Rainbow Dot Laser Foil 产品详情页

## 变更原因
根据 `面料独立站产品数据.xlsx` 新增 H2013090104 产品详情页，并按当前产品详情页生成规则整理图片、文案、规格、SEO 和公开产品集合。

## 变更前
H2013090104 未进入 `performanceProducts` 公开产品集合，也没有对应的静态产品详情页。图片素材尚未按详情页展示逻辑连续编号，也缺少对应 WebP 展示版本。

## 变更后
新增公开产品 `rainbow-dot-laser-foil-knit-fabric`。页面使用 Excel 中确认的英文 H1、产品描述、应用、关键特征和规格，并按新增产品 SEO 规则将 SEO 标题补充为美国采购商搜索型 `Wholesale Supplier` 标题。确认参数包括：150 cm / 59 in、90 GSM、MOQ 200 m / 219 yd、slight stretch、90S、hot-stamping foil、knit fabric 和 100% Polyester。

详情图按内容重新排序并连续编号为 `x1`–`x23`。对应 WebP 已生成，PNG/JPG 原图保持无水印，除首张主图外的主图和详情图 WebP 每张使用 3 个低透明度、逆时针 45 度倾斜 `nixiafabric.com` 水印。本次素材未发现独立 application 图片目录，因此未新增 Application 图。

详情页遵循统一模板，不显示独立 `Product Description` 模块。颜色数量、批量交期和测试合规未在来源数据确认，因此页面保持 to be confirmed，不编造具体颜色数、交期或认证信息。

## 验收条件
- `/products/rainbow-dot-laser-foil-knit-fabric/` 能生成并展示。
- 公开产品集合增加至 8 个产品，目录、详情静态路由和询盘产品选择同步包含 H2013090104。
- 详情图连续编号为 `x1`–`x23`，且按内容顺序展示。
- PNG/JPG 原图保持无水印；`main/a1.webp` 不加水印；其余主图和详情图 WebP 每张包含 3 个低透明度、逆时针 45 度倾斜域名水印。
- 页面显示来源数据已确认参数，不编造颜色数量、批量交期或测试合规。
- 页面包含 Key Features、Recommended Applications、Why Choose、Ready Stock & Custom Development、Sample CTA 和 FAQ。
- `Specifications Table for B2B Buyers` 前不显示 `Product Description` 模块。
