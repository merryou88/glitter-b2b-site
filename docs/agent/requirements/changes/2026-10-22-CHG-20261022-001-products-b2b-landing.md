# Products 页批发采购首屏优化

## 变更原因
用户采纳产品列表页广告落地页审核建议，并明确本次只修改 Products，不修改 Home。

## 变更前
首屏以 Foil Fabrics for Dancewear & Performance Costumes 为标题，包含省 50% 和所有款式免费 A4 样品的笼统承诺，无首屏专用 quote/sample 双入口；桌面搜索和五个下拉控件挤在同一行，部分选项文字截断。

## 变更后
- H1 使用 Wholesale Metallic Fabrics for Dance & Stage Costumes，简短描述明确工厂直供 foil/弹力面料及服装制造商、舞蹈服品牌客户，不将整个目录统一称为四面弹。
- 移除省 50% 与所有款式免费 A4 样品文案；展示现货 MOQ from 50m、定制 MOQ from 200m、样品选项与 OEM 支持；说明现货色卡免费、买家支付运费、定制样品可能收费。
- 首屏新增 Request Bulk Quote 和 Request Samples，复用现有 RFQ 意图选择、弹窗、提交和追踪流程。
- 用户进一步要求首屏优先看到产品：移除重复 eyebrow，将两段介绍合成一句，样品条件下移至产品网格后的底部 CTA，移动标题缩为 24px、按钮保持并排；宽屏桌面将标题排成一行，并将搜索及五个筛选控件放在一行，避免 Hero 与筛选重复占用垂直空间。
- 桌面搜索独占一行，下拉控件以自适应网格展开，缩短默认选项标签；不改筛选值和匹配逻辑。
- 本变更替代 REQ-SHELL-017 旧首屏文案与 REQ-PRODUCT-022 旧桌面控件排列；此前间距、网格、卡片和移动筛选规则继续有效。

## 验收条件
桌面及移动端文案、采购条件、按钮可读且无横向溢出；375px/390px 手机宽度下首图顶部小于 450px，宽桌面不超过 410px；quote/sample 打开正确询盘意图；搜索、筛选、排序、清除筛选及移动 Dancewear 默认筛选可用；产品集合与默认首卡不变；Home 和其他页面源码不修改。

## 影响范围
仅 `src/pages/products.astro` 及对应需求与模块文档。

## 兼容性
保留现有 SEO 元数据、路由、产品数据和询盘组件。无 JavaScript 时按钮可回退到联系页或样品政策页。不部署、不提交 Git、不发送真实测试询盘。

## 实现位置
`src/pages/products.astro`，以及 current/product-catalog.md、current/site-shell.md、requirements/INDEX.md、modules/product-catalog.md。

## 验证结果
- 最终 `npm run build` 通过：18 个公开产品、59 个 HTML 页面、56 个 sitemap URL 及站内链接校验通过；`git diff --check` 通过，公开页面源码变更仅限 `src/pages/products.astro`。
- 本地 Chrome 检查 375px、390px、768px、1024px、1280px、1440px：无页面横向溢出、CTA 重叠或筛选选项截断；quote/sample 意图、关闭弹窗、桌面搜索/筛选/排序/清除、移动应用筛选及断点恢复均通过，未提交真实询盘。
- 375px/390px 手机首图顶部约 393px，移动 Hero 高约 261px；更新后宽桌面标题与搜索筛选同行；1280px/1440px 首图顶部约 388px，1024px 为 448px；18 个目录产品和默认首卡保持不变，移动默认 Dancewear 显示 17 个产品。
- 已查看 390px 和 1440px 截图；真实广告留存率、邮件投递和广告转化未验证。

本次用户的产品落地页截图、采纳优化建议与仅修改 Products 页的明确要求；样品与 MOQ 以现有产品数据规则为准。
