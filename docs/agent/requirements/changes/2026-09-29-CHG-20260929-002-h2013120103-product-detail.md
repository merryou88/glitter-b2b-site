# H2013120103 渐变彩虹点箔针织提花面料产品详情页

## 变更原因
用户确认 H2013120103 产品素材已存放在 `public/images/products/H2013120103/`，并要求生成该产品详情页。当前产品详情页生成规则要求：所有产品事实先读取 `products-data/面料独立站产品数据.xlsx` 的 `Independent Site Product Data` sheet，再使用图片素材补充展示。

## 变更前
- H2013120103 未进入 `performanceProducts` 公开产品集合。
- `public/images/products/H2013120103/` 中只有 PNG 素材，未生成站点引用的 WebP 展示图。
- 候选计划中 H2013120103 仍记录为需要与 H2013090103、H2013090104 完成图案和采购场景去重。

## 变更后
- 新增公开产品 `gradient-rainbow-dot-foil-knit-fabric`，SKU 为 H2013120103。
- 页面数据以 `面料独立站产品数据.xlsx` 的 `Independent Site Product Data` sheet 中 H2013120103 行为准：H1 为 `Gradient Rainbow Dot Foil Knit Fabric for Stage Costumes`，SEO 标题为 `Gradient Rainbow Dot Foil Knit Fabric for Stage Costumes | Nixia Fabric`。
- 页面定位为 gradient rainbow dot foil、lightweight knit jacquard 和 stage costume fabric，推荐应用为 stage costumes、performance wear、dancewear 和 costume accessories。
- 规格按表格确认：150 cm / 59 in、90 GSM、MOQ 200 m / 219 yd、15 colors、slight stretch、30D、hot-stamping foil、knit jacquard 和 92% Polyester 8% Spandex。密度、库存、测试合规和贸易条款保持 `To be confirmed` 或项目确认表述。
- 主图整理为 `a1.webp`-`a5.webp`；详情图按内容顺序整理为 `x1.webp`-`x11.webp`；应用拼图独立为 `application/1.webp` 和 `application/2.webp`。
- PNG 原图归档到 `products-data/original-images/images/products/H2013120103/`，线上目录只保留 WebP。
- `main/a1.webp` 无水印；其余主图和详情图 WebP 各添加 3 个低透明度、逆时针 45 度倾斜的 `nixiafabric.com` 域名水印；应用图不加水印。
- 详情页不输出独立 `Product Description` 模块。

## 验收条件
- `/products/gradient-rainbow-dot-foil-knit-fabric/` 能生成并进入公开产品集合。
- 产品目录、静态路由、询盘产品选择和相关推荐使用 `performanceProducts` 中的 13 个产品。
- 页面包含 Key Features、Recommended Applications、Why Choose、Ready Stock & Custom Development、Sample CTA 和 FAQ。
- 页面字段先读取 `Independent Site Product Data` 中 H2013120103 行；未提供来源的密度、库存、测试合规和贸易条款保持待确认或项目确认表述。
- 页面源码不包含独立 `Product Description` 标题，且不引用 H2013120103 PNG 原图。

## 影响范围
产品数据、产品公开集合、H2013120103 图片资源、产品详情页和候选产品计划。
