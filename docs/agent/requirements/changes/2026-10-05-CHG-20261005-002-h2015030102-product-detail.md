# H2015030102 Gold Rainbow Gradient Metallic Foil 产品详情页

## 变更原因
根据用户确认新增 H2015030102 产品详情页，并按当前产品详情页生成规则整理数据、图片、SEO、采购字段和公开产品集合。

## 变更前
H2015030102 未进入 `performanceProducts` 公开产品集合，也没有对应的静态产品详情页。图片素材为 JPG 原图，尚未生成线上 WebP 展示图或归档原图。

## 变更后
新增公开产品 `gold-rainbow-gradient-metallic-foil-4-way-stretch-fabric`。产品事实以 `面料独立站产品数据.xlsx` 的 `Independent Site Product Data` sheet 中 H2015030102 行为第一来源，确认参数包括：150 cm / 59 in、200 GSM、MOQ 200 m / 219 yd、41 stock colors or customized colors、4-way stretch、40D*40D、foil finish、foil construction 和 80% Nylon 20% Spandex。

主图生成 4 张 WebP；色卡生成 17 张 WebP 并作为 SKU Color Gallery 展示。JPG 原图已按原路径结构归档到 `products-data/original-images/images/products/H2015030102/`，线上 `public/images/products/H2015030102/` 仅保留 WebP 展示图。主图首张 WebP 不加水印，其余主图 WebP 每张使用 3 个低透明度、逆时针 45 度倾斜 `nixiafabric.com` 域名水印；色卡 WebP 不加水印。

详情页遵循统一模板，不显示独立 `Product Description` 模块。测试合规和贸易条款未在来源数据确认，因此页面保持 to be confirmed 或项目确认表述。

## 验收条件
- `/products/gold-rainbow-gradient-metallic-foil-4-way-stretch-fabric/` 能生成并展示。
- 公开产品集合增加至 16 个产品，目录、详情静态路由和询盘产品选择同步包含 H2015030102。
- 页面显示 41 stock colors、150 cm / 59 in、200 GSM、MOQ 200 m / 219 yd、4-way stretch、40D*40D 和 80% Nylon 20% Spandex。
- 页面包含 Key Features、Recommended Applications、Why Choose、Ready Stock & Custom Development、Sample CTA、FAQ 和 Color Options。
- 构建产物不引用 H2015030102 的 JPG 原图，所有新增 WebP 单张低于 500 KB。
- `Specifications Table for B2B Buyers` 前不显示 `Product Description` 模块。
