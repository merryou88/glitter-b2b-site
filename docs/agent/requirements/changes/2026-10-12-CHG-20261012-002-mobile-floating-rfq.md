# 移动端左下方浮动询盘入口

## 变更原因
移动端采购用户需要在浏览产品时快速打开现有询盘表单。
## 变更前
询盘依赖页面内按钮，无左下方固定入口。
## 变更后
挂载 RFQ 弹窗的页面在不超过 640px 的视口显示 50px 固定询盘图标，避让安全区；复用现有表单、产品上下文规则、关闭和焦点恢复逻辑。弹窗打开时隐藏入口，桌面端隐藏。
## 验收条件
移动端入口位于左下方，点击可打开表单，关闭恢复入口与焦点；右侧联系方式保持可用；桌面隐藏。
## 影响范围
RFQ 弹窗组件及挂载它的页面；首页现有内联表单不变。
## 兼容性
不改变提交字段、Worker、邮件或转化逻辑。
## 实现位置
`src/components/RFQQuoteModal.astro`
## 验证结果
`npm run build` 通过（含产品校验和 SEO 校验）。本地 390×844 产品目录页验证入口可见、点击打开现有弹窗、打开时入口隐藏、关闭后恢复；1280px 桌面验证入口隐藏。未提交询盘，不涉及邮件发送联调。
## 来源
用户要求在移动端左侧下方添加浮动图标，点击打开现有询盘表单。
