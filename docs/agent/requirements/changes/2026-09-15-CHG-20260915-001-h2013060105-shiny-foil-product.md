# H2013060105 Shiny Foil 产品详情页

## 变更原因
新增 H2013060105 产品详情页，并让页面内容符合 Nixia Fabric 当前 Performance & Party Wear Fabric 的 B2B 定位。

## 变更前
H2013060105 未进入当前公开产品集合，站点没有对应静态产品详情页。

## 变更后
新增 `shiny-foil-4-way-stretch-knit-fabric` 产品数据和公开详情页。页面使用指定 H1、SEO 标题、Meta Description、Key Features、Recommended Applications、Why Choose、Ready Stock & Custom Development、Sample CTA 和 FAQ。产品规格来自 `面料独立站产品数据.xlsx` 中 H2013060105 的确认字段，并避免把 Shoes、Bags、Crafts、Hair Accessories 作为主要应用方向。

同时修正 `Layout` 的 `og:image:type`，让 PNG 产品主图输出 `image/png`。

补充修正：H2013060105 详情页遵循统一模板，不显示独立 `Product Description` 模块；PNG 原图保持无水印，除 `main/a1.webp` 外，其余主图、Application 图和 Product Details 图的 WebP 展示版本均添加每张 3 个、逆时针 45 度倾斜的低透明度域名水印 `nixiafabric.com`。

## 验收条件
- `/products/shiny-foil-4-way-stretch-knit-fabric/` 能生成并展示。
- 页面应用聚焦 Stage Costumes、Dancewear、Performance Wear、Concert Outfits、Party Wear、Festival Costumes、Performance Bodysuits。
- 规格显示 145cm、150g、100m MOQ、30 colors、100% Polyester、4-way stretch、90S 和 hot-stamping foil，不编造未确认参数。
- Sample CTA 使用现有询盘流程并带当前产品上下文。
- FAQ schema 和页面 FAQ 内容一致。
- PNG 产品主图的 Open Graph 图片类型输出为 `image/png`。
- `Specifications Table for B2B Buyers` 前不显示 `Product Description` 模块。
- PNG 原图保持无水印；`main/a1.webp` 保持无水印；其他 H2013060105 WebP 展示图每张只包含 3 个低透明度、逆时针 45 度倾斜域名水印。

## 影响范围
公开产品集合从 4 个增加到 5 个；询盘产品选择和相关产品推荐会读取新的 `performanceProducts` 成员。

## 兼容性
