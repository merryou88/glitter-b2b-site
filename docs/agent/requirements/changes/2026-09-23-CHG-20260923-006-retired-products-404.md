# Retired Product URLs Return 404

## 变更原因
用户确认4个已经退出当前经营方向、且没有明确同类替代页面的旧产品URL不应继续301到产品目录，应由站点返回404。

## 变更前
以下不带尾斜杠的旧产品地址统一301到 `/products/`：

- `/products/non-woven-glitter-fabric`
- `/products/rainbow-gradient-glitter-synthetic-leather`
- `/products/coarse-glitter-pu-hot-stamping-fabric-cma-certified`
- `/products/sparkle-glitter-surface-solid-leather-fabric`

## 变更后
删除上述4条301规则。由于这些产品不属于 `performanceProducts`，Astro不会生成对应静态详情页；带斜杠和不带斜杠的旧地址均由现有站点404页面处理。

## 验收条件
- `_redirects` 不再包含上述4个旧产品到 `/products/` 的规则。
- 构建产物不生成上述4个产品详情页。
- sitemap不包含上述4个产品URL。
- 构建产物不存在指向上述4个产品详情页的公开链接。
- 当前11个公开产品仍正常生成并通过校验。
- `npm run build` 和 `git diff --check` 通过。

## 影响范围
只改变4个已退出产品旧URL的响应方式；不改变当前公开产品、产品目录、详情页内容或其他重定向。

## 兼容性
旧外部链接将进入品牌404页面，不再被送到不相关的产品目录。Google后续抓取时会将这些URL归类为未找到。

## 实现位置
- `public/_redirects`
- `docs/agent/requirements/current/product-catalog.md`
- `docs/agent/requirements/INDEX.md`

## 验证结果
- 通过：`npm run build`，共生成 41 个页面。
- 通过：`npm run validate:products`，11 个公开产品全部通过校验。
- 通过：4个旧产品地址均已从 `_redirects` 删除。
- 通过：构建产物未生成4个旧产品详情页。
- 通过：sitemap不包含4个旧产品URL。
- 通过：公开HTML中不存在指向4个旧产品详情页的链接。
- 通过：品牌 `404.html` 正常生成。
- 通过：`git diff --check`。

## 来源
用户明确要求4个旧产品地址转到404。
