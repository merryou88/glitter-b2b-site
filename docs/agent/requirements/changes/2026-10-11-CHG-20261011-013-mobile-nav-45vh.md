# 移动端展开菜单高度优化

## 变更原因
移动端导航展开后占据页面高度过大，影响首页首屏内容浏览。

## 变更前
移动端菜单使用固定 `max-height: 600px`，菜单项和询盘按钮间距较大。

## 变更后
在 `max-width: 768px` 下，展开菜单最大高度调整为 `45vh`，并压缩链接、按钮和区块间距；超出内容在菜单面板内部滚动。

## 验收条件
- 375px、390px 和 768px 视口下，展开菜单约占视口 45%。
- Home、Products、Applications、Factory、About Us、Blog、Contact 和询盘按钮仍可访问。
- 桌面导航和其他页面布局不受影响。

## 影响范围
仅调整 Header 移动端展开菜单的高度、间距和字号。

## 实现位置
`src/components/Header.astro`

待执行构建验证。
