# H2013120104 彩虹指纹点箔冰丝针织面料产品详情页

## 变更原因
用户确认 H2013120104 产品素材已存放在 `public/images/products/H2013120104/`，并要求生成该产品详情页。当前产品详情页生成规则要求：所有产品事实先读取 `products-data/面料独立站产品数据.xlsx` 的 `Independent Site Product Data` sheet，再使用图片素材补充展示。

## 变更前
- H2013120104 未进入 `performanceProducts` 公开产品集合。
- `public/images/products/H2013120104/` 中只有 PNG 素材，未生成站点引用的 WebP 展示图。
- 候选计划中 H2013120104 因宽度、克重、MOQ、弹性、密度、纱支和工艺字段缺失而不进入当前优先队列。

## 变更后
- 新增公开产品 `rainbow-fingerprint-dot-foil-ice-silk-fabric`，SKU 为 H2013120104。
- 页面数据以 `面料独立站产品数据.xlsx` 的 `Independent Site Product Data` sheet 中 H2013120104 行为准：H1 为 `Rainbow Fingerprint Dot Foil Stretch Knit Fabric`，SEO 标题为 `Rainbow Fingerprint Dot Foil Ice Silk Stretch Knit Fabric | Nixia Fabric`。
- 页面定位为 rainbow fingerprint-dot foil、ice-silk knit 和 stretch knit direction，推荐应用为 dresses、tops、formalwear、stage costumes 和 dancewear。
- 来源行状态为 partial source data；宽度、克重、MOQ、底材、颜色数量、密度、纱支、工艺和花型结构未确认，因此页面保持 `To be confirmed` 或项目确认表述。
- 主图整理为 `a1.webp`-`a5.webp`；详情图按内容顺序整理为 `x1.webp`-`x14.webp`；应用拼图独立为 `application/1.webp`。
- PNG 原图归档到 `products-data/original-images/images/products/H2013120104/`，线上目录只保留 WebP。
- `main/a1.webp` 无水印；其余主图和详情图 WebP 各添加 3 个低透明度、逆时针 45 度倾斜的 `nixiafabric.com` 域名水印；应用图不加水印。
- 详情页不输出独立 `Product Description` 模块。

## 验收条件
- `/products/rainbow-fingerprint-dot-foil-ice-silk-fabric/` 能生成并进入公开产品集合。
- 产品目录、静态路由、询盘产品选择和相关推荐使用 `performanceProducts` 中的 14 个产品。
- 页面包含 Key Features、Recommended Applications、Why Choose、Ready Stock & Custom Development、Sample CTA 和 FAQ。
- 页面字段先读取 `Independent Site Product Data` 中 H2013120104 行；未提供来源的规格和采购字段保持待确认或项目确认表述。
- 页面源码不包含独立 `Product Description` 标题，且不引用 H2013120104 PNG 原图。
