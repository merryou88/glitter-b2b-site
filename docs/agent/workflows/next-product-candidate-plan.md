# 下一批产品候选筛选与上架准备

## 目标
在不虚构产品资料、不以 SEO 数量为目标的前提下，从工厂实际可供应、可寄样、可报价的产品中筛选下一批 3–5 个候选产品。候选产品必须经过用户确认后，才能进入产品页制作。

## 当前基线
- 当前公开产品集合为 `performanceProducts` 中的 11 款产品。
- 本轮不质疑现有已公开产品及图片的真实性，不回退现有产品页。
- 两个尚未满足正式上架条件的产品继续等待，不因本计划自动进入候选、制作或发布队列。
- 当前本地资料源包括 `面料独立站产品数据.xlsx`、`产品分类.xlsx`、`关键词分析.xlsx`、现有产品图片目录、Search Console 查询和业务确认信息。
- `关键词分析.xlsx` 当前只有表头，没有可用于排序的搜索量数据；Search Console 查询数据也未保存在仓库中，因此搜索价值必须在取得真实查询数据后复核。

## 状态定义
| 状态 | 判定标准 | 允许动作 |
|---|---|---|
| 可立即上架 | 工厂确认可供应、可寄样、可报价；核心规格、MOQ、样品、交期、应用和合格图片齐全；与现有产品定位不重复；用户已确认 | 可进入页面制作排期 |
| 待补资料 | 产品方向有候选价值，但至少一项供货确认、采购字段、图片、视频、应用证据、搜索证据或差异说明缺失 | 只补资料和复核，不制作页面 |
| 暂不上架 | 不符合当前 performance fabric 定位、与现有产品高度重复、供货条件不稳定、属于两个继续等待的产品，或用户不批准 | 保留记录，不进入制作队列 |

## 产品资料核验表
每个候选产品必须逐项记录来源和确认人，不能用同类产品数据代填。

| 类别 | 必填内容 | 验证方式 |
|---|---|---|
| 产品身份 | 产品编号、中文名称、拟用英文名称、实物与 SKU 对应关系 | 产品表、色卡、样布或业务确认 |
| 供货条件 | 是否可供应、库存状态、可报价、标准 MOQ、定制 MOQ、批量交期 | 工厂或业务书面确认 |
| 样品 | 是否可寄样、样品尺寸、样品准备时间、运费规则 | 样品流程或业务确认 |
| 规格 | 材质、克重、门幅、弹性、密度、纱支、染整、表面效果、颜色政策 | 规格表、实测或业务确认 |
| 应用 | 推荐应用、限制场景、至少一项真实应用证据 | 实物、客户应用图或业务确认 |
| 素材 | 主图、表面近景、拉伸/手感、背面、色卡、应用图、可选视频 | 原始图片/视频文件检查 |
| 定制 | 可定制颜色、花型、底布、门幅、包装或标签，以及对应 MOQ | 工厂确认和报价规则 |
| 搜索价值 | Search Console 查询、展示、点击、平均排名；美国采购词和采购场景 | GSC 导出与查询意图复核 |
| 差异说明 | 与现有 8 款产品在材质、表面、弹性、应用和主关键词上的差异 | 产品对比表和页面基线 |

## 评分与门槛
1. 真实性为否决项。无法确认供货、寄样或报价的产品不得入选。
2. 用户确认为否决项。未获用户确认不得开始页面制作。
3. 搜索价值、询盘价值、差异化和资料完整度各按 0–5 分记录，但总分不能覆盖否决项。
4. Search Console 没有对应查询时，不等于产品没有价值；需结合美国采购场景、真实询盘和产品差异判断。
5. 与现有产品主关键词、H1 意图和采购用途高度重合时，默认降级为 `暂不上架`，除非能证明独立采购需求。

## 单款发布后检查
1. 确认产品 URL 出现在 sitemap，页面 canonical、robots 和结构化数据正确。
2. 在 Search Console 提交或检查 URL，并记录索引状态和检查日期。
3. 在 GA4 DebugView 或实时报告确认 `product_view`，参数至少包含产品标识和 `product_path`。
4. 从该产品页打开并测试 RFQ，确认表单、GA4 事件和邮件中的产品/SKU 归因一致。
5. 记录发布后 7 天和 14 天的索引、展示、点击、`product_view`、RFQ 打开和有效询盘情况。
