## Visit Our Factory 布局修复（部署后错乱）
- 问题：部署后双栏布局错乱，iframe 撑破页面
- 修复内容：
  1. 移除 iframe 所有行内属性（`style="border:0;border-radius:12px"`、`width="100%"`、`height="400"`）
  2. 新增 `.map-iframe-wrap` CSS class 包裹容器：`width:100%;height:400px;overflow:hidden;border-radius:12px`
  3. iframe CSS 改为 `width:100%;height:100%;border:0`，高度由外层 wrap 控制
  4. grid gap 从 `var(--space-4xl)`(6rem) 改为 `2rem`
  5. 移动端断点从 `968px` 改为 `767px`（`<768px` 堆叠）
  6. 降级脚本 `showFallback()` 从 `wrapper.style.display='none'` 改为 `classList.add('visit-factory__map--hidden')`
- dist 产物验证通过：HTML/CSS 结构正确，无行内样式，全部文本保留
- git commit + push 已完成（0bf79b9）

  3. 降级时隐藏 iframe，显示 fallback 卡片（地址 + "View on Google Maps" 金色按钮链接）
  4. 降级时 grid 切换为单列布局（`visit-factory__grid--map-failed`），左侧信息占满宽度
- 海外客户可正常看到 Google Maps iframe；国内访问者看到 fallback 卡片
